# DH Lotto 45

Connects your [DH Lottery](https://dhlottery.co.kr) (Korea's official Lotto 6/45 operator) account to Home Assistant.
Buy tickets automatically or manually, follow the weekly winning numbers and your results, watch your deposit
balance, and see hot/cold number statistics. Sensors are created through MQTT Discovery, and a REST API with
Swagger UI is included. Up to four family accounts are supported, each limited to the weekly 5-game cap.

동행복권 로또 6/45 계정을 Home Assistant에 연결합니다. 자동·수동 구매, 당첨번호·구매 결과 확인,
예치금 모니터링, 번호 통계를 제공하며 최대 4개 계정을 지원합니다.

Setup guide and sensor list: [project page](https://github.com/redchupa/ha-app-dhlottery).
